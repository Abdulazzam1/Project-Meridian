# Project Meridian · Workforce Capability Console

Working prototype for a Rakamin Product Consultant case study (capability-based workforce transformation).

**Live:** https://abdulazzam1.github.io/Project-Meridian/

- Single self-contained HTML file (`index.html`): no build step, no login, no external data.
- Primary user: Director of Human Capital. Five steps, from the AI-exposure map to the Day-90 Board decision.
- AHA moment: Step 2 · Field Metering → "Show the people behind the 4,200".
- The client is masked. All people and figures are synthetic or stated assumptions.
